    按入场日（本机时区）分组；「去掉最好一笔」= 这天净盈亏减去当天最赚的那一笔——一天的账是不是一个币撑起来的。持有至今的尾仓算在入场那天，早入场的尾仓多跑了几天，跨日比未实现要留心

    逐笔

    全部成交，按净盈亏排序
    买入（等了多久 · 相对首喊价）代币买入市值投入成交退出 / 估值持有最后倍数期间最高已实现未实现净盈亏

    注意

    • 语言越自由越容易把这几天拟合出一条漂亮曲线；看验证段、看「去掉最好一笔」、看 n。
    • 成交按 20s 采样价、不计冲击（小池子里 $100 也会推价）；跳空时按观测到的那一价成交。
    • 价格路径剔了两类坏点：供应量口径跳变、同名大币的错报价（一步跳 ≥20× 又回落）——不设止损时一段假报价就能把尾仓「赚」出几万。
    • 入场只能用决策截面看到的信息；带截面的币从装上这一版起才开始积累，推特 / 买入人类 chip 前几天多为 0。
    • 策略跑在 sidecar 的 worker 线程里，15s 超时；不是安全沙箱，别粘贴不认识的人写的策略。
    step(s) / entry(t) 能看到什么
    s.x s.mc s.liq当前采样 ÷ 入场价的倍数、当前市值、当前流动性 USD（没给 = null）
    s.peakX s.dd入场后最高倍数、从最高点回撤比例（0–1）
    s.held s.windowLeft s.ts入场后秒数、离 24h 窗末还剩几秒（「拿满就卖」写 windowLeft <= 60）、当前采样时刻
    s.holding s.buy(usd, tag)有没有仓位；watch 模式下按当前采样价买入（默认每单），每个币只能买一次。买之前 s.x 等相对首喊价，买入后相对买入价
    s.callX s.callPeakX s.callMinX s.sinceCall始终相对首喊价：当前倍数 / 首喊后最高 / 首喊后最低 / 首喊后秒数——「看 15 分钟再决定」用这几个
    s.remaining s.fills s.sold(x)剩余原始仓位比例（没买 = 0）、成交记录 [{x, pct, ts, mc, tag}]、有没有 ≥x 倍的成交
    s.sell(pct, tag) s.sellAll(tag)按当前价卖原始仓位的 pct（0–1）；tag 是退出原因标签，页面按它分组
    s.state s.token这个币私有的空对象，跨 step 保留（记「已经出本」之类）；s.token = entry 看到的同一个 t（watch 模式在 step 里再查卡片 / 官推）
    s.groups s.callers s.events.calls到现在为止喊过这个币的群数 / 人数（含首喊）；逐条 [{ts, grp, sender}]
    s.events.tweets s.events.gmgn s.events.fomo推文 [{ts, kind, actor, followers, kol}]、GMGN 喊单 [{ts, actor, followers, kol}]、fomo 关注者 [{ts, kind: buy|sell|thesis, handle, usd}]——都只到当前采样为止
    t.mc t.liq t.chain t.symbol入场市值 / 流动性 / 链 / 代号
    t.ageSec t.openSec首喊 − 代币创建（秒）；首喊 − 迁出 / 开盘（秒），负 = 还在内盘。不知道 = null
    t.card群里机器人在首喊后几秒回的卡片（近 12 天 2/3 的喊单有）：holders 持有人 · volume 成交量 · mc · groups 已有几个群在聊（firstCall = 我们是 16 个群里第一个）· sinceX 机器人侦测后已涨几倍（追高）；没有卡片 = null
    t.prior首喊人先验 {n, hit, rate}：这个人（同群）之前已完结的首喊里 ≥2× 的比例；没历史 = null
    t.firstGroup t.firstSender t.text首喊的群 / 人 / 消息文本
    t.twitter官推 {has, joined, isTweet, tweetAgeSec, followers}：有没有链接、账号注册时刻（不随拉升变）· isTweet 链接指向一条推文（/status/）而不是账号主页 · tweetAgeSec 首喊 − 被链接推文发出时刻 · followers 粉丝数；不知道 = null
    t.features t.cut喊单那一刻为真的特征 id（Set；id 见复盘页特征表）· 决策截面原始字段（09-14 起才有）
    entry(t) 返回数字 = 立刻买这么多美元；0 / null / false = 不买；不返回 = 默认每单立刻买；"watch" = 先看着，之后在 step 里 s.buy() 再买（到窗末没买 = 放弃，计「观察未买」）。不写 entry = 全部合格币立刻买
